# 📖 تطبيق «حافظ القرآن» - رفيقك في حفظ كتاب الله

تطبيق إسلامي متكامل لحفظ القرآن الكريم وتثبيته ومراجعته الذكية، يحتوي على المصحف الشريف كاملاً برواية حفص عن عاصم بالرسم العثماني المعتمد، وتلاوة الشيخ محمد صديق المنشاوي (مرتل)، ونظام الحفظ الذكي بالمراحل الخمس، وميزة «سمّعني» الصوتية، والأذكار والأدعية النبوية، والمسبحة الإلكترونية، ولوحة إحصائيات الإنجاز، مع العمل **Offline بالكامل دون الحاجة إلى الإنترنت**.

---

## 🌟 الميزات المنفذة في المشروع (كاملة وتعمل فعلياً)

### 1. المصحف الشريف بالرسم العثماني
- **114 سورة كاملة** و **6,236 آية** وفق مصحف المدينة النبوية المعتمد.
- **30 جزءاً** و **60 حزباً** وأرباع الأحزاب.
- **604 صفحات** مطابقة لترتيب صفحات المصحف الشريف.
- عرضان للمصحف: **عرض السورة المتصل** و **عرض الصفحات (Page by Page)**.
- قائمة إجراءات الآية: استماع بصوت المنشاوي، تكرار الآية (1x، 3x، 5x، 10x)، بدء الحفظ الذكي، التسميع الصوتي، الإشارات المرجعية، ونسخ نص الآية.

### 2. محرك التلاوة بصوت الشيخ محمد صديق المنشاوي (مرتل)
- تلاوة الآيات بصوت الشيخ محمد صديق المنشاوي برواية حفص عن عاصم.
- تشغيل السورة كاملة، تشغيل آية واحدة، وتكرار الآية أو المدى الصوتي.
- التحكم في سرعة التلاوة (0.75x، 1.0x، 1.25x).
- دعم **التشغيل في الخلفية والشاشة مقفلة (Android MediaSession API / Media3)**.
- تخزين التلاوات محلياً في الذاكرة (IndexedDB Blob Cache) للعمل Offline بنسبة 100%.
- إمكانية استيراد ملفات MP3 محلية من جهاز المستخدم.

### 3. نظام الحفظ الذكي (المراحل الخمس)
1. **المرحلة الأولى (التلاوة والتكرار)**: عرض الآية مع تكرار صوت الشيخ المنشاوي بعدد محدد.
2. **المرحلة الثانية (الإخفاء التدريجي)**: 4 مستويات إخفاء للكلمات مع إمكانية النقر للمساعدة.
3. **المرحلة الثالثة (اختبار الإكمال)**: اختبار تفاعلي لاختيار الكلمات المفقودة في الآية.
4. **المرحلة الرابعة (ترتيب الآيات)**: ترتيب الآيات المبعثرة بالترتيب القرآني الصحيح.
5. **المرحلة الخامسة (المراجعة والتثبيت)**: استرجاع الآيات وتقييم الأداء بنظام التكرار المتباعد.

### 4. ميزة «سمّعني» (Voice Recitation Assistant)
- تسجيل صوت القارئ وتحليله محلياً للمقارنة مع النص القرآني.
- تلوين الكلمات: **أخضر** للكلمات المتقنة، و**أحمر** للكلمات المنسية أو التي تحتاج مراجعة.
- حساب نسبة الدقة والإتقان مع تنبيه واضح بأن الميزة للمساعدة وليست حكماً تجويدياً شرعياً.

### 5. المراجعة الذكية (Spaced Repetition Algorithm)
- خوارزمية SM-2 لتحديد مواعيد المراجعة تلقائياً بناءً على تقييم المستخدم.
- تصنيف الآيات: جديدة، قيد الحفظ، جيدة، متقنة، وتحتاج مراجعة.
- إعادة جدولة الآيات الضعيفة في اليوم التالي، وتوسيع الفترات للآيات المتقنة (يوم -> 3 أيام -> أسبوع -> شهر -> 3 أشهر).

### 6. خطة الحفظ والورد اليومي (وردي اليوم)
- لوحة متابعة يومية تشمل: إنجاز الحفظ، المراجعة، أذكار الصباح والمساء، وعدد التسبيحات.
- نسبة إتمام الورد اليومي مع عداد الأيام المتتالية (🔥 7 أيام متتالية).

### 7. وضع الأطفال (Kids Mode)
- واجهة مبهجة ومبسطة ومناسبة للأعمار من 7 إلى 12 سنة.
- نظام النجوم (⭐)، الشارات التشجيعية (🏆)، واحتفالات Confetti عند الإنجاز.

### 8. الأذكار والأدعية الموثوقة
- أذكار الصباح والمساء والنوم والاستيقاظ وبعد الصلاة المفروضة والطعام ودخول وخروج المنزل والسفر.
- أدعية من القرآن الكريم، وأدعية نبوية صحيحة، والاستغفار والتسبيح والصلاة على النبي ﷺ.
- ذكر الفضل والمصدر لكل ذكر (صحيح البخاري، صحيح مسلم، سنن أبي داود، الترمذي، حصن المسلم).
- عداد تفاعلي مع اهتزاز لمسي (Haptic Feedback).

### 9. المسبحة الإلكترونية
- صيغ الأذكار النبوية المتنوعة.
- أهداف محددة (33، 100، 1000، أو مفتوح).
- قرص تسبيح لمسي مع اهتزاز وحفظ الإجمالي التراكمي محلياً.

### 10. محرك البحث الفوري في القرآن
- بحث سريع وفوري في جميع آيات القرآن الكريم (6,236 آية).
- بحث ذكي غير حساس للتشكيل والهمزات.
- انتقال مباشر لموضع الآية في المصحف.

### 11. النسخ الاحتياطي والاستعادة
- تصدير كامل بيانات الحفظ والمفضلة والإعدادات في ملف JSON محلي.
- استعادة البيانات بنقرة واحدة لنقلها بين الأجهزة.

### 12. سلامة وموثوقية النص القرآني
- أداة فحص آلي في الإعدادات تؤكد:
  - عدد السور = 114 سورة.
  - عدد الآيات = 6,236 آية.
  - ترتيب السور صحيح تماماً.
  - النص لم يُولَّد بواسطة الذكاء الاصطناعي ومطابق لمصحف المدينة النبوية.

## 🛠️ بناء تطبيق Android Native (APK Release & Debug)

تم تضمين الكود المصدري الأصلي لتطبيق Android Native في مجلد `/android/`:
- **لغة البرمجة**: Kotlin
- **واجهة المستخدم**: Jetpack Compose و Material 3
- **قاعدة البيانات**: Android Room Database
- **محرك الصوت**: AndroidX Media3 (ExoPlayer + MediaSessionService)

### خطوات بناء ملفات APK عبر السطر البرمجي:

1. **بناء Debug APK**:
```bash
cd android
./gradlew assembleDebug
```
المسار الناتج: `android/app/build/outputs/apk/debug/app-debug.apk`

2. **بناء Release APK**:
```bash
cd android
./gradlew assembleRelease
```
المسار الناتج: `android/app/build/outputs/apk/release/app-release-unsigned.apk`

## 📱 التثبيت كـ Progressive Web App (PWA / WebAPK)

التطبيق مدعوم بالكامل كـ PWA مع Service Worker:
1. افتح رابط التطبيق على هاتف Android عبر Google Chrome.
2. اضغط على القائمة (⋮) ثم اختر **«تثبيت التطبيق»** أو **«إضافة إلى الشاشة الرئيسية»**.
3. يعمل التطبيق بعد ذلك كتطبيق هاتف مستقل بدون إنترنت وبشاشة كاملة.

## 🗄️ Database Schemas (مخطط قواعد البيانات)

### 1. مخطط Android Room (`AppDatabase.kt`):
- `QuranSurahEntity` (id, nameArabic, nameSimple, revelationPlace, versesCount, startPage, endPage)
- `QuranAyahEntity` (id, surahId, verseNumber, verseKey, textUthmani, pageNumber, juzNumber, hizbNumber)
- `MemorizationEntity` (verseKey, masteryLevel, easeFactor, repetitionsCount, intervalDays, nextReviewDate)
- `BookmarkEntity` (id, type, surahId, verseNumber, pageNumber, title, createdAt)
- `DhikrProgressEntity` (dhikrId, categoryId, count, totalDone, lastUpdated)

### 2. مخطط الويب المحلي (`HafizAlQuranDB` IndexedDB):
- `memorization`: سجلات الحفظ والتكرار المتباعد
- `bookmarks`: الإشارات المرجعية
- `ward_progress`: تقدم الورد اليومي
- `sebha_stats`: إحصائيات المسبحة
- `user_settings`: إعدادات الخط والتفضيلات
- `audio_cache`: ملفات التلاوة الصوتية المخزنة محلياً Blobs

## 🔒 التحقق والتراخيص

1. **نص القرآن الكريم**: مأخوذ من المصادر المعتمدة المفتوحة لمصحف المدينة النبوية بالرسم العثماني القياسي (Tanzil / Quran.com API standard canonical data). لم يتم توليد أو تعديل أو تغيير أي حرف أو تشكيل بواسطة AI.
2. **التلاوات الصوتية**: تلاوة الشيخ محمد صديق المنشاوي (مرتل) من الأرشيف العام المفتوح (EveryAyah.com - Minshawy Murattal 128kbps) للاستخدام القرآني الخيري غير التجاري.
3. **الأذكار**: نصوص مأخوذة من حصن المسلم، وصحيحي البخاري ومسلم، والسنن المعتمدة مع عزو المصادر.
